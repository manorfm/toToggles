Basics

The API is served by your toToggle instance. Replace the example host with your server URL.

Base URL
https://toggles.example.com

Public endpoints use an application scoped secret key in the X-API-Key header. Generate it from the application page in the admin interface.

Protect your key Keep keys in a secrets manager or environment variable. A key grants access only to its own application.

Read toggles

GET/api/toggles

Returns the application catalogue and each toggle with its own enabled state and activation rule. SDKs evaluate the hierarchy and rules locally.

cURL
curl https://toggles.example.com/api/toggles \
  -H "X-API-Key: $TOTOGGLE_SECRET_KEY"
Response
{
  "application": {
    "id": "01APP...",
    "name": "Checkout Web",
    "revision": "7c5c5f3e...",
    "toggles": [
      { "path": "user.payments", "enabled": true }
    ]
  }
}

Efficient polling

Responses include an ETag based on the catalogue revision. Send it back with If-None-Match and a current catalogue returns 304 Not Modified.

cURL
curl https://toggles.example.com/api/toggles \
  -H "X-API-Key: $TOTOGGLE_SECRET_KEY" \
  -H 'If-None-Match: "7c5c5f3e..."'

Disable a toggle immediately

POST/api/toggles/disable

The kill switch disables one toggle by path. It never enables a toggle or changes activation rules. Requests are limited to 30 per key in five minutes.

cURL
curl -X POST https://toggles.example.com/api/toggles/disable \
  -H "X-API-Key: $TOTOGGLE_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"path":"user.payments"}'

A successful response returns 200 with the path and enabled set to false. The request is idempotent.

Administrative routes

Routes for applications, application toggle lists and enable or disable actions are used by the admin application. They require an authenticated same origin session and the appropriate user role.

Not part of the public integration API A secret key cannot list applications, list an application catalog by ID, enable a toggle or manage users and teams. External services should use the catalogue endpoint and, when needed, the disable only kill switch above.
