Set up toToggle

Run the server, create an application and connect a client library in a few clear steps.

Run the server

The server includes the admin application and applies database migrations when it starts.

1
Get the source

Clone the repository and enter the server directory.

2
Build the admin application

Install the frontend dependencies and produce the static files served by Go.

3
Start toToggle

Open the admin application at http://localhost:3056.

Terminal 
git clone https://github.com/manorfm/toToggles.git
cd toToggles/server
make web-install web-build
make dev
First login The first start creates a root user and writes a one time password to initial-root-password.txt in the database directory. Change that password at the first login.

Server settings

The defaults work for local development. Set environment variables before starting the server when you need different values.

Terminal 
SERVER_PORT=8080 DB_PATH=./db/totoggle.db make dev

Create an application and key

Every SDK connects to one application with an application scoped secret key.

1
Sign in to the admin application

Use the root password from the first start and set a new password.

2
Create an application

Open Applications and create the application your service will use.

3
Generate a secret key

Open the application and select Generate Secret Key. Store the value in a secret manager because it is shown only once.

Keep the key private Pass the key to your service through an environment variable such as TOTOGGLE_SECRET_KEY. Do not put it in browser code or commit it to the repository.

Set up the Java SDK

Add one dependency, provide the server URL and secret key, then start the client with your application.

Add the dependency

Gradle Kotlin DSL 
implementation("io.github.manorfm:totoggle_java:1.0.0")
Maven POM 
<dependency>
  <groupId>io.github.manorfm</groupId>
  <artifactId>totoggle_java</artifactId>
  <version>1.0.0</version>
</dependency>

Configure and start the client

Java 
import com.totoggle.client.ToToggleClient;
import com.totoggle.client.ToToggleClientRuntime;
import com.totoggle.client.config.ToToggleConfig;
import java.time.Duration;

ToToggleConfig config = ToToggleConfig.Companion.builder()
    .applicationName("my-app")
    .serverUrl("http://localhost:3056")
    .secretKey(System.getenv("TOTOGGLE_SECRET_KEY"))
    .refreshInterval(Duration.ofMinutes(5))
    .enableOfflineMode(true)
    .build();

ToToggleClient client = new ToToggleClient(
    config,
    ToToggleClientRuntime.Companion.production("my-app")
);
client.start();

boolean enabled = client.isActive("user.payments");

Call client.shutdown() when your application stops. The client fetches the catalog at startup and refreshes it in the background.

Set up the Go SDK

Install the module, create a configuration with your application details and start the client before evaluating a flag.

Terminal 
go get github.com/manorfm/toToggles/totoggle_go
Go 
package main

import (
    "context"
    "log"
    "os"

    totoggle "github.com/manorfm/toToggles/totoggle_go"
)

func main() {
    config, err := totoggle.NewConfig(
        "my-app",
        "http://localhost:3056",
        os.Getenv("TOTOGGLE_SECRET_KEY"),
    )
    if err != nil {
        log.Fatal(err)
    }

    client := totoggle.New(config)
    if err := client.Start(context.Background()); err != nil {
        log.Fatal(err)
    }
    defer client.Shutdown()

    enabled := client.IsActive("user.payments")
    log.Println(enabled)
}

Use NewConfig to validate the application name, server URL and key before the client is created.

Set up the Node SDK

Install the package, read the secret key from your environment and start the client before it serves requests.

Terminal 
npm install totoggle-node
Node 
import { createConfig, ToToggleClient } from "totoggle-node";

const config = createConfig(
  "my-app",
  "http://localhost:3056",
  process.env.TOTOGGLE_SECRET_KEY ?? "",
);

const client = new ToToggleClient(config);
await client.start();

const enabled = client.isActive("user.payments");
console.log(enabled);

client.shutdown();

createConfig validates the required values and the client keeps the catalog in memory for local evaluation.
