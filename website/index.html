Self hosted feature flags
with clients for every stack.

toToggle is a Go server with a role based admin UI, team management and an optional approval workflow. Its three official client libraries fetch and cache toggles locally while evaluating seven activation rule types with cascading validation.

Why toToggle

Hierarchical toggles

service.feature.flag paths with cascading validation. A disabled parent disables every descendant.

7 activation rules

Percentage rollout, attribute, user ID, IP/CIDR, country, time window, and cohort.

Local evaluation

Every client caches the catalog in memory so evaluation never blocks on the network.

Approval workflow

Optional propose, approve and execute flow for sensitive changes with a full audit trail.

Client libraries
